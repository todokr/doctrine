# Deno をやめて Node に移る Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** dctl と pfd を廃止したうえで、core・shared を Deno から Node 26 + TypeScript（型の除去だけで実行）に移し、`dctld` の単一バイナリを `deno compile` から Node SEA に置き換える。

**Architecture:** 最初に dctl（CLI）と pfd（`pfd/` の CLI とスキル）を消し、移行する量を減らす。core・shared を pnpm workspace にまとめ、`node` で `.ts` を直接走らせる。`Deno.*` は互換層を作らずに `node:*` を直接呼ぶ。子プロセスだけは起動失敗の扱い（Node では非同期の `error` イベントで来る）を 1 か所に閉じるため `util/exec.ts` に `spawnChild` を置く。単一バイナリは esbuild で ESM 1 ファイルにまとめてから `node --build-sea` で作る。

**Tech Stack:** Node 26.8.1（mise）、pnpm 11.15.1、TypeScript ~6.0.3（`tsc --noEmit` で型検査のみ）、`node:test` + `node:assert/strict`、esbuild、Biome、Kysely + `node:sqlite`、zod、yaml

**Spec:** 独立した spec 文書は無い。前提は会話で決めた次の事柄。
- Deno の開発終了を受けて Node に移る（Bun / Rust / Go は採らない）
- 配布は将来 Tauri の externalBin で dctld を同梱し、brew の Cask で配る。そのため単一バイナリが要る
- dctl は廃止する（アプリの画面があれば要らない）。SEA は 1 本 144MB あり、dctl と dctld の 2 本にするとアプリが約 290MB 重くなることも理由の一つ
- Quick Start の同梱ワークフローの validate ステップは `dctl workflow-check` をやめ、`git status` の確認だけにする（YAML の誤りは apply の後、読み込み時のエラーとして見える）
- pfd（`pfd/` の CLI と `pfd/skill/pfd-decompose`）は廃止する。Intake の PFD（`core/src/intake/pfd`・アプリの PFD 表示）は別物なので残す
- 事前検証（2026-10-14、scratchpad）で次を確かめた:
  - `node --build-sea` に `mainFormat: "module"` を渡すと ESM のまま SEA にでき、`node:sqlite`・unix ソケット・`child_process.spawn`・`import.meta.main` が動く
  - SEA には 1 ファイルしか入らないので、esbuild の `--bundle --format=esm` でまとめる。yaml が CJS の `require` を呼ぶので `createRequire` を banner で差し込む
  - macOS では SEA を作った後に `codesign --sign - -f` しないと SIGKILL（exit 137）で落ちる
  - tsc（`erasableSyntaxOnly`）で引っかかるのは parameter properties の 3 クラスだけ（`db/boundary.ts`・`db/intakes.ts`・`tracker/tracker.ts`）

## Global Constraints

- Node は `mise.toml` の `node = "26.8.1"`。`engines` に `"node": ">=26.8.1"` を書く
- 依存の版は今の deno.lock の解決結果に揃える: `zod` 3.25.76（app と同じ）、`yaml` 2.9.1、`kysely` 0.28.17
- TypeScript は app と同じ `~6.0.3`。`@types/node` は `^26`（無ければ入手できる最新の 26 系に合わせる）
- `Deno` 互換の薄い層（`Deno.readTextFile` を真似た関数群など）は作らない。`node:fs/promises` などを直接呼ぶ。後方互換の仕掛けも作らない（利用者はまだいない）
- コードコメントには、そのコード固有の事実だけを書く。一般論は書かない。Deno の挙動を前提にした既存コメントは Node の事実に書き直す
- `.ts` の import は拡張子付きのまま（`"./foo.ts"`）。型だけの import は `import type` で書く（tsc の `verbatimModuleSyntax` が検査する）
- 全 package.json は `"type": "module"` と `"private": true`
- 単一バイナリは `dctld` の 1 本だけ
- `shared/guide/examples/step-artifacts.patch` は過去の差分の例示データなので書き換えない

## Review Focus

1. **`claude` や `gh` が入っていない環境でステップを走らせる** — タスクが失敗として記録され、dctld は落ちない。Node の `spawn` は存在しないバイナリでも同期では投げず、`error` イベントを誰も聞いていなければプロセスごと落ちる。→ Task 3 で `spawnChild` のテストに入れる
2. **クライアント（アプリの relay）が応答を待たずに切断した後にデーモンが書き込む** — `EPIPE` が来ても dctld は落ちない。`net.Socket` の `error` イベントも聞かなければプロセスが落ちる。→ Task 5 のテストに入れる
3. **大きな git 出力（1MB を超える diff やツリー）** — `runCommand` は切り詰めずに全部返す。`execFile` の `maxBuffer` の既定値（1MB）で落ちないようにする。→ Task 3 のテストに入れる
4. **`clearEnv` 付きの呼び出し（captureTree の `GIT_DIR` / `GIT_WORK_TREE`）** — 親の環境変数が子に漏れない。Node の `spawn` の `env` は「置き換え」なので、Deno の「重ねる」とは向きが逆になる。→ Task 3 のテストに入れる
5. **前回の dctld が残したソケットファイルがある状態で起動する** — 生きていなければ消して起動し、生きていれば二重起動を拒む。`Deno.errors.ConnectionRefused` は `ECONNREFUSED` に変わる。→ Task 5 のテストに入れる

import { type ChildProcess, spawn } from "node:child_process";
import type { Readable } from "node:stream";

export type ExitStatus = { code: number | null; signal: NodeJS.Signals | null };

export type Child = {
  pid: number;
  stdout: Readable;
  stderr: Readable;
  status: Promise<ExitStatus>;
  kill(signal?: NodeJS.Signals): void;
};

/**
 * stdin を閉じ、stdout / stderr をパイプにして子プロセスを起こす。
 * 存在しないコマンドや cwd は `spawn` が同期では投げず `error` イベントで来るので、
 * `spawn` イベントか `error` イベントのどちらかを待ってから返す。
 */
export function spawnChild(
  cmd: string,
  args: string[],
  opts: { cwd?: string; env?: Record<string, string> },
): Promise<Child> {
  return new Promise((resolve, reject) => {
    let proc: ChildProcess;
    try {
      proc = spawn(cmd, args, { cwd: opts.cwd, env: opts.env, stdio: ["ignore", "pipe", "pipe"] });
    } catch (e) {
      reject(e);
      return;
    }
    const status = new Promise<ExitStatus>((res) => {
      proc.once("close", (code, signal) => res({ code, signal }));
    });
    proc.once("error", reject);
    proc.once("spawn", () => {
      proc.off("error", reject);
      // 起動後の error（kill の失敗など）でプロセスが落ちないように聞いておく。
      proc.on("error", () => {});
      resolve({
        pid: proc.pid!,
        stdout: proc.stdout!,
        stderr: proc.stderr!,
        status,
        kill: (signal = "SIGTERM") => {
          proc.kill(signal);
        },
      });
    });
  });
}

/**
 * 外部コマンドを最後まで走らせ、stdout / stderr を文字列で返す。
 * 非0終了は例外にする — 呼び出し側（git / ps）は失敗を例外として扱う前提で書かれている。
 */
export async function runCommand(
  cmd: string,
  args: string[],
  opts: { cwd?: string; env?: Record<string, string>; clearEnv?: boolean } = {},
): Promise<{ stdout: string; stderr: string }> {
  // spawn の env は親の環境を置き換える。親が持つ変数を消したい呼び出し
  // （captureTree の GIT_DIR / GIT_WORK_TREE）だけが clearEnv を立て、env をそのまま渡す。
  const env = opts.clearEnv ? opts.env : opts.env && { ...process.env, ...opts.env };
  const child = await spawnChild(cmd, args, { cwd: opts.cwd, env: env as Record<string, string> });
  const [status, stdout, stderr] = await Promise.all([
    child.status,
    readAll(child.stdout),
    readAll(child.stderr),
  ]);
  if (status.code !== 0) {
    throw new Error(`Command failed: ${[cmd, ...args].join(" ")}\n${stderr}`);
  }
  return { stdout, stderr };
}

async function readAll(stream: Readable): Promise<string> {
  const chunks: Buffer[] = [];
  for await (const c of stream) chunks.push(c as Buffer);
  return Buffer.concat(chunks).toString("utf8");
}

/** 子プロセスの終了コード。シグナルで殺された場合は null。 */
export function exitCodeOf(status: ExitStatus): number | null {
  return status.code;
}
```

import { build } from "esbuild";
import { execFileSync } from "node:child_process";
import { mkdir, rm, writeFile } from "node:fs/promises";
import { fileURLToPath } from "node:url";

const root = fileURLToPath(new URL("..", import.meta.url));
const dist = `${root}dist`;
const bundle = `${dist}/dctld.mjs`;
const config = `${dist}/dctld.sea.json`;
const output = `${dist}/dctld`;

// yaml は CJS のまま `require("process")` を呼ぶ。ESM の出力には require が無いので差し込む。
const banner =
  'import { createRequire } from "node:module"; const require = createRequire(import.meta.url);';

await rm(dist, { recursive: true, force: true });
await mkdir(dist, { recursive: true });

await build({
  entryPoints: [`${root}src/daemon/main.ts`],
  bundle: true,
  platform: "node",
  format: "esm",
  target: "node26",
  outfile: bundle,
  banner: { js: banner },
});
await writeFile(config, JSON.stringify({
  main: bundle,
  mainFormat: "module",
  output,
  disableExperimentalSEAWarning: true,
}));
execFileSync(process.execPath, ["--build-sea", config], { stdio: "inherit" });
// macOS は埋め込みで署名が壊れ、署名し直さないと起動時に SIGKILL される。
if (process.platform === "darwin") {
  execFileSync("codesign", ["--sign", "-", "--force", output], { stdio: "inherit" });
}
await rm(bundle);
await rm(config);
```

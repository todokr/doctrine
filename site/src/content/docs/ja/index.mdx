## 判断以外は、doctrine に。

エージェントに任せた作業は、決めた手順どおりに進む。人に届くのは、判断が要るものだけ。

<FeatureRow title="Epic をまるごと渡す">
  大きな Issue は、レビューしきれる PR 1 つ分ずつに割る。その前に、判断が要る論点を質問にまとめて返す。いきなりコードを書き始めはしない。
  <FeatureDiagram slot="visual" variant="split" />
</FeatureRow>

<FeatureRow title="マージしたら、次が動く">
  上流の PR がマージされると、それを待っていた下流のタスクが自動で始まる。何を待っていたか覚えておく必要も、コマンドを叩く必要もない。
  <FeatureDiagram slot="visual" variant="flow" />
</FeatureRow>

<FeatureRow title="conflict は自分で直す">
  PR を開いた後に baseBranch とぶつかっても、取り込んで直し、テストを通して push し直す。手元でブランチを直す必要はない。
  <FeatureDiagram slot="visual" variant="conflict" />
</FeatureRow>

<FeatureRow title="上限に当たっても、続きから">
  Claude の利用上限で止まっても、途中の作業は捨てない。枠が戻れば、同じ会話の続きから再開する。
  <FeatureDiagram slot="visual" variant="limit" />
</FeatureRow>

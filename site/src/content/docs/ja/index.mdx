## 人の手は判断にだけ使う

エージェントに任せた作業は、事前に定めた手順に沿って進む。判断以外の作業は doctrine が引き受ける。

<CardGrid>
  <Card title="Epic の分割支援" icon="puzzle">
    Epic 粒度の Issue を、PR 1 つでレビューしきれるプロセスに PFD で分解する。論点は質問として先にまとめて届く（[Intake](/ja/concepts/features/#intake--pfd-による分解)）
  </Card>
  <Card title="依存関係に沿った投入" icon="list-format">
    上流の PR がマージされると、その成果物を待っていた下流のタスクが自動で作られる（[Intake](/ja/concepts/features/#intake--pfd-による分解)）
  </Card>
  <Card title="conflict の自動修復" icon="random">
    PR を開いた後に baseBranch と conflict したら、取り込んで直し、テストを通して push し直す（[マージ待ち](/ja/concepts/features/#マージ待ちと-conflict-の自動修復)）
  </Card>
  <Card title="利用上限からの自動再開" icon="rocket">
    Claude の利用上限に当たっても作業は捨てられず、枠が明ければ同じ会話から続く（[利用上限での待機](/ja/concepts/features/#利用上限での待機)）
  </Card>
</CardGrid>
